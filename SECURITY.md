# Security Policy

## Reporting a Vulnerability

Scott Labz takes the security of our digital infrastructure and data systems seriously. If you believe you have discovered a vulnerability, misconfiguration, or security issue within our applications or repositories, please report it responsibly.

* **Preferred Reporting Method:** Please review our full [Vulnerability Disclosure Policy (VDP)](https://scottlabz.com/vdp.html).
* **Direct Contact:** Send details securely to **info@scottlabz.com**.

Please include as much information as possible to help us triage and remediate the issue rapidly, including step-by-step reproduction instructions and proof-of-concept code where applicable. We appreciate the security research community's efforts in keeping our ecosystem safe.
