The Lottery Matrix Case Study

Every Draw, Measured Against Chance

The Lottery Matrix is a statistics site for Powerball and Mega Millions that updates itself after every drawing from official results, and shows every number next to what pure chance would produce.

Project Overview

Project A live statistics site for Powerball and Mega Millions
Organization The Lottery Matrix
Timeline Built October 13 to 23, 2026. Live October 23, 2026
At launch Every Powerball draw since November 1997 (3,294) and every Mega Millions draw since December 2003 (2,388)
Services Code audit, data sourcing and verification, automated updates, interactive statistics, homepage, search data, accessibility, and legal pages
Live site thelotterymatrix.com

The Challenge

In 2015 the Powerball Matrix was a small site that collected the winning numbers after every drawing and showed them in a grid: every number, broken down by the position it was drawn in. It went quiet around 2017. By 2026 its data source was gone, its history had stopped, and its code had been copied into more than a dozen near-identical pages.

A read-through of the original code found the grid worth keeping, and a list of problems worth fixing:

  • The results file the site depended on now returns a 404
  • Powerball has changed its ball ranges five times since 1997, and the old counts mixed them together. Of 2,096 archived draws, only 225 were played under today's rules, so older numbers looked "hot" simply because they had existed longer
  • The headline count mixed white balls with the red Powerball, and a date filter compared dates as text, so it kept draws by month instead of by date
  • Fourteen page variants, from Wednesday-only to averages, were the same hundred lines with small edits
  • The original promised to find "a pattern in randomness," but every draw is independent

The rebuild had to be fun to explore without implying it could predict anything. Five decisions set the direction:

  • Open to everyone and to search engines, with no accounts or sign-ups
  • No ads: the old offshore lottery affiliate ads would not come back
  • Powerball first, on a design that could take more games
  • Official results, fetched in code from a government source rather than a scraped copy
  • No social integrations and no contact forms

A source that keeps the order the balls were drawn

The matrix only works if the white balls arrive in the order they were drawn. Results feeds usually sort them low to high, which throws that away. Of the official sources checked, one state lottery agency's results file keeps the drawn order and updates within minutes of each drawing.

  • Before trusting it, the file was checked against the original archive: all 817 drawings they share matched, with zero mismatches
  • That joined the archive (1997 to 2010) and the official file (2010 on) into one continuous, verified Powerball history
  • For Mega Millions, the same agency has every drawing since December 2003, and only about 1% of rows come out already sorted, which is what random order produces

Counts compared within one set of rules

Every game is split into rule eras: six for Powerball and five for Mega Millions. Each era's start date was checked against the data, and every era's ball numbers fit its rules exactly. Counts are only ever compared within one era, and the newest era is the default.

Updates itself after every drawing

  • A scheduled job runs the morning after each Powerball drawing (Monday, Wednesday and Saturday) and each Mega Millions drawing (Tuesday and Friday), plus a daily safety pass
  • Every incoming row is checked: a valid date, five different white balls within that era's range, and a bonus ball and multiplier within bounds
  • A short or failed download never overwrites the last good copy, and unchanged data costs one request and no write
  • The whole Powerball history since 1997 downloads as about 33 KB compressed, and every statistic is worked out in the browser
  • Plain HTML, CSS and JavaScript, with no build step, no framework and no dependencies

Found by search

  • Search-friendly titles and descriptions, canonical addresses, a sitemap and robots file, and the www address redirected to the bare domain
  • Structured data for the site, each page and its breadcrumbs, each game as a web application, and each draw history as a dataset, which makes it eligible for dataset search

The Results

The Lottery Matrix went live on October 23, 2026, with both games updating on their own after every drawing.

  • Every Powerball draw since November 1997 across six verified rule eras, and every Mega Millions draw since December 2003 across five, where the old site had stopped in November 2017
  • The key figures were recounted in a separate script straight from the raw official files, and every one matched the live pages
  • All three Powerball randomness checks come back consistent with chance
  • Fourteen copied pages replaced by one engine and a settings file per game
  • A page-quality audit of the live homepage scored 99 for performance on desktop, and 100 for best practices and SEO on phone and desktop
  • No ads, where the old site ran offshore lottery affiliate ads

Business Impact

The Lottery Matrix keeps itself current from official results and is plain about what the numbers mean. Every statistic sits next to what chance would produce, so the site is fun to explore without suggesting it can predict a draw.

Built on one engine, the next game is a settings file, a data source and a homepage card away. Through web application development and data work, it follows the same habits as client projects: check the source before trusting it, recount the numbers independently, and test in a real browser.
