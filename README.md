# Scott Labz

**Independent Analytics & Digital Engineering Firm**

Scott Labz, LLC provides analytics engineering, web development, and digital infrastructure consulting, serving the Bloomington-Normal, Illinois area and clients nationwide. This repository contains the source for our production website, [scottlabz.com](https://scottlabz.com).

## Services

- Web Development
- Analytics Implementation
- Data Quality & Governance
- Reporting & Insights
- Automation & Digital Infrastructure

## Security

We take a security-first approach to development and deployment:

- Responsible disclosure via our [Vulnerability Disclosure Policy](https://scottlabz.com/trust/vdp.html)
- Privacy-focused analytics and data handling
- Secure deployment practices, including automated dependency and code scanning

See [SECURITY.md](SECURITY.md) to report a vulnerability.
