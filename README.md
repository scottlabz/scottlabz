# Scott Labz

**Independent Analytics & Digital Engineering Firm**

Scott Labz, LLC provides analytics engineering, web development, and digital infrastructure consulting, serving the Bloomington-Normal, Illinois area and clients nationwide. This repository contains the source for our production website, [scottlabz.com](https://scottlabz.com).

## Services

Our work is organized around four pillars:

1. **[Analytics & Data Solutions](https://scottlabz.com/analytics-data.html)** - Analytics implementation, data quality & validation, reporting & data integration.
2. **[Web Development & Digital Solutions](https://scottlabz.com/web-digital.html)** - Custom website development, web applications & integrations, performance & optimization.
3. **[Optimization & Continuous Improvement](https://scottlabz.com/conversion-optimization.html)** - User behavior analysis, experimentation & validation, continuous improvement.
4. **[Advertising & Media Buying](https://scottlabz.com/advertising-media-buying.html)** - Campaign strategy & planning, media buying & execution, tracking & attribution.

See the full breakdown on [scottlabz.com/services.html](https://scottlabz.com/services.html).

## Security

We take a security-first approach to development and deployment:

- Responsible disclosure via our [Vulnerability Disclosure Policy](https://scottlabz.com/trust/vdp.html)
- Privacy-focused analytics and data handling
- Secure deployment practices, including automated dependency and code scanning

See [SECURITY.md](SECURITY.md) to report a vulnerability.
